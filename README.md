# glad-thicket-mini



折腾中的小玩具

## 用法

```bash
cat data.txt | cargo run
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 安装

```bash
git clone https://github.com/USER/glad-thicket-mini.git
cd glad-thicket-mini
cargo build --release
```
